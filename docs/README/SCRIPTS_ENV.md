# SCRIPTS_ENV

Module: `scripts/_env.sh`

## Purpose

Shared paths, SteamVR helpers, UI target list, and logging for Asterism scripts.

## Notes

- Defaults under `~/.local/state/asterism`, `~/.local/share/asterism/backups`, `$XDG_RUNTIME_DIR/asterism`.
- `asterism_ui_targets` lists Phase C candidate Valve files; Phase B does not modify them.
