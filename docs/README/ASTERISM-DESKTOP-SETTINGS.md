# ASTERISM-DESKTOP-SETTINGS

Script: `desktop-settings/asterism-desktop-settings`

## Purpose

Host launcher for Asterism Desktop Settings. Attaches to nested Plasma (`asterism-shell-env.sh`) then execs `asterism_desktop_settings.py`.

## Notes

Same wrapper idea as FrameTop `display-settings/ft-display-settings` + `session/ft-shell-env.sh` ([AZumD/frametop](https://github.com/AZumD/frametop)), without distrobox.

Full UI docs: [DESKTOP-SETTINGS.md](DESKTOP-SETTINGS.md).
