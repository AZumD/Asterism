# ASTERISM-SHELL-ENV

Script: `desktop-settings/asterism-shell-env.sh`

## Purpose

Capture / load nested Asterism plasmashell environment (`…/asterism_nested/plasmashell.env`) without `eval`.

## Notes

Adapted from FrameTop `session/ft-shell-env.sh` ([AZumD/frametop](https://github.com/AZumD/frametop)); runtime path is `asterism_nested` instead of `frametop`. Used by `asterism-desktop-settings` so SSH launches reach the VR desktop display.
