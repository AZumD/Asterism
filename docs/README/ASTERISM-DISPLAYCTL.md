# ASTERISM-DISPLAYCTL

Script: `scripts/asterism-displayctl`

## Purpose

CLI backend for display topology (`~/.config/asterism/displays.json`).

## Usage

```
asterism-displayctl list --json
asterism-displayctl add --resolution 1920x1080
asterism-displayctl set display-1 scale 1.25
asterism-displayctl set-primary display-1
asterism-displayctl apply
```
